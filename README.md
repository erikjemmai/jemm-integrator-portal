# Jemm Integrator Portal

Prototype for the Jemm integrator portal (static HTML, CSS, and JavaScript).

**Live preview:** https://erikjemmai.github.io/jemm-integrator-portal/

## Run locally

```bash
python3 serve.py
```

Then open http://localhost:5174

Sign in with any email and password — the demo loads a finished property. Use **Quick setup** to walk through onboarding.

This build is a prototype with sample data, not a production app.
